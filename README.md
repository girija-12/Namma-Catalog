# 🛒 NammaCatalog

**NammaCatalog** is a multilingual, web-based AI agent designed to assist farmers, artisans, and kirana store owners in creating and managing digital product catalogs using voice, text, or image inputs. This project was developed as part of **Hackfinity 2025**, the world’s first prompt-only hackathon focused on agentic AI.

**Live Demo** 👉 [Visit NammaCatalog](https://namma-catalog.netlify.app/)

## 🚀 Project Overview

During a 24-hour hackathon at SIMATS Engineering, Chennai (15–16 July 2025), our team built **NammaCatalog** to solve the real-world challenge of enabling small-scale sellers with low digital literacy to maintain structured online catalogs.

Our solution uses agentic AI to provide a **bilingual assistant (Tamil + English)** capable of understanding natural user input and transforming it into structured inventory data.

---

## 🧠 Core Features

- 🔊 **Voice and Text-Based Catalog Creation**
  - Accepts speech input in Tamil and English
  - Automatically extracts fields such as product name, category, quantity, price, and description

- 🖼️ **Image-Based Product Recognition**
  - Analyzes product images to auto-fill relevant catalog data

- 🗣️ **AI Chatbot Assistant**
  - Guides users in natural language to complete their catalog entries
  - Switches dynamically between Tamil and English

- 🧾 **AI-Driven Description Suggestions**
  - Generates product categories and short descriptions using GPT

- 📦 **Inventory Monitoring**
  - Tracks inventory levels and raises alerts for low-stock items

- 🌐 **Multilingual UI**
  - Seamless Tamil-English interface switching based on user choice

## ⚙️ Tech Stack

### 🖥️ Frontend
- [Vite](https://vitejs.dev/) + [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/) for utility-first styling
- [ShadCN UI](https://ui.shadcn.com/) for modern React components
- Browser `MediaRecorder` API for audio capture

### ☁️ Backend & AI Integration
- [Convex](https://www.convex.dev/) for real-time backend functions and cloud database
- [OpenAI GPT-4o](https://openai.com/gpt-4o) for prompt-based structured data extraction
- [Whisper](https://openai.com/whisper) API for multilingual speech-to-text processing
